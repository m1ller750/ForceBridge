# ForceBridge

**Платформа для поиска людей в команду: на конкурсы, хакатоны, олимпиады и в научные исследования.**

Пользователь регистрируется, заполняет паспорт участника и публикует карточку-объявление: «ищу сокомандника на конкурс» или «нужен человек для исследования». Другие откликаются, а автор открывает профили откликнувшихся, связывается с ними через указанный мессенджер и добавляет сильных кандидатов в избранное.

Главная фишка — встроенный ИИ (Groq):
- **Совместимость.** Открываете объявление — ИИ сравнивает его с вашим профилем (навыки, проекты, достижения, город, формат) и показывает процент совместимости с объяснением: что подходит и чего не хватает.
- **Категории для фильтра.** ИИ читает каждое новое объявление и относит его к одной или нескольким категориям — они записываются в базу данных. Изменили объявление — ИИ разберёт его заново, удалили — оно исчезнет из базы и из всех категорий. Поэтому фильтр точный и быстрый: он работает по готовым меткам в базе.

## Что умеет приложение

| Раздел | Возможности |
|---|---|
| Регистрация | Почта и пароль, затем паспорт участника. Обязательно: имя, возраст, город, чем занимаетесь, мессенджер (Telegram, WhatsApp, Instagram, TikTok, ВКонтакте, Discord, телефон) и юзернейм или номер |
| Профиль | О себе, навыки, проекты, достижения, загрузка резюме (PDF, Word, фото до 1,8 МБ; большие фото сжимаются сами) |
| Объявления | Лента с поиском, фильтром по ИИ-категориям, фильтром по типу и сортировкой: новые, старые, ближайший дедлайн, по совместимости. В углу каждой карточки — дата создания |
| Карточка | Подробное описание, кого ищут, формат, дедлайн, категории от ИИ и процент совместимости от ИИ. Кнопка «Откликнуться» с сообщением автору |
| Отклики | Автор видит список откликнувшихся, открывает их профили, резюме и контакты, может убрать человека из списка или добавить в избранное |
| Кабинет | Вкладки «Профиль», «Мои объявления» (изменить или удалить — изменится или удалится у всех), «Избранное», «Мои отклики» |
| Карта сил | SpriteKit-граф: объявления притягиваются к категориям ИИ; режим «Совместимость» ставит вас в центр |
| Скан афиши | Vision распознаёт текст на фото афиши и заполняет объявление: название события, даты, город |

## Архитектура

```
iOS-приложение (SwiftUI, без сторонних библиотек)
        │  HTTPS + токен входа
        ▼
Cloudflare Worker  — server/src/index.ts
  ├── вход и регистрация (пароли: PBKDF2, токены: SHA-256 в базе)
  ├── профили, резюме, объявления, отклики, избранное
  ├── проверка прав: менять и удалять можно только своё,
  │   отклики на объявление видит только его автор
  ├── ИИ-категории: после создания или изменения объявления,
  │   плюс досчёт «зависших» по расписанию раз в 10 минут
  └── ИИ-совместимость с кэшем: пересчёт, когда меняется объявление или профиль
        │
        ├──▶ Cloudflare D1 (SQLite): users, sessions, profiles, resumes, cards,
        │                           card_categories, responses, favorites, compatibility
        └──▶ Groq API (ключ хранится только в секретах Cloudflare)
```

Категории объявления лежат в отдельной таблице `card_categories` с индексом, поэтому фильтр — это быстрый запрос к готовым меткам, а не работа ИИ в момент поиска.

## Технологии (для формы заявки)

| Технология | Где используется |
|---|---|
| **SwiftUI** | Весь интерфейс, навигация, формы, анимации, собственный `Layout` для тегов, `Canvas` для чертёжных элементов |
| **SpriteKit** | «Карта сил» — силовой граф: узлы отталкиваются, связи работают как пружины |
| **Vision** (раздел «Core ML / Vision») | `VNRecognizeTextRequest` распознаёт русский и английский текст на афишах |
| **UIKit** | Адаптивные цвета для тёмной темы, буфер обмена, сжатие фото, шрифты в SpriteKit |
| **Swift Playgrounds** | Проект в формате `.swiftpm`, собирается на iPad |
| **Xcode** | Тот же пакет открывается в Xcode |
| Другие | Cloudflare Workers и D1 (сервер и база данных), Groq API (ИИ), PhotosUI, QuickLook, Keychain (Security) |

## Как запустить

### Приложение

Откройте `ForceBridge.swiftpm` в **Xcode 16+** или в **Swift Playgrounds 4.6+** и запустите на iPhone, iPad или в симуляторе (iOS 17 или новее). Адрес сервера уже указан в `App/ServerConfig.swift`.

### Сервер (если разворачиваете свой)

```bash
cd server
npm install
npx wrangler login
npx wrangler d1 create forcebridge      # вставьте database_id в wrangler.toml
npx wrangler deploy
npx wrangler secret put GROQ_API_KEY    # ключ Groq вводится в терминале и не попадает в код
```

Схема базы создаётся сама при первом запросе. Демо-объявления можно загрузить скриптом:

```bash
API=https://<ваш-адрес>.workers.dev node seed/demo.mjs
```

Ключ Groq не хранится ни в приложении, ни в репозитории — только в секретах Cloudflare.

## Дизайн

- Три цвета: тёплая чертёжная бумага, тушь и «международный оранжевый» — цвет, которым красят мосты. Без градиентов, теней и эмодзи.
- Широкий SF Pro Expanded в заголовках, SF Mono в технических подписях, New York в цитатах.
- Фирменные элементы: ферма-мост как индикатор и глиф «кого ищут», штамп инженерного чертежа в профиле, линейки, чертёжная сетка на карте.
- Поддерживаются тёмная тема, VoiceOver, iPhone и iPad.

## Структура

```
ForceBridge.swiftpm/
├── App/          точка входа, навигация, панель вкладок, адрес сервера
├── Design/       палитра, шрифты, компоненты, ферма, штамп чертежа
├── Model/        модели данных и форматирование
├── Network/      клиент API, сессия в Keychain, разбор дат
├── Store/        состояние приложения
└── Features/
    ├── Auth/     вход, регистрация, паспорт участника
    ├── Feed/     лента, поиск, фильтр и сортировка
    ├── Cards/    карточка, отклик, редактор объявления
    ├── People/   профиль участника
    ├── Cabinet/  кабинет и редактор профиля
    ├── Map/      «Карта сил» (SpriteKit)
    ├── Scanner/  распознавание афиш (Vision)
    └── Shared/   строки списков
server/
├── src/index.ts  API: Cloudflare Worker + D1 + Groq
├── seed/demo.mjs демо-данные
└── wrangler.toml настройки развёртывания
```

Демо-участники и их объявления вымышлены; их контакты заведомо ненастоящие.
